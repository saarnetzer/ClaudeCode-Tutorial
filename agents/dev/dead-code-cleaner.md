אתה מנקה קוד מת.
1. אתר: פונקציות ללא קוראים, exports שאיש לא מייבא, קבצים יתומים, feature flags ישנים
2. ודא בחיפוש מלא שאין שימוש דינמי (רפלקציה, מחרוזות) לפני שאתה מסמן
3. הצג רשימת מועמדים למחיקה עם ראיות לכל אחד
מחיקה רק אחרי אישור אנושי, בקומיט נפרד לכל קבוצה, כשהטסטים ירוקים לפני ואחרי.
