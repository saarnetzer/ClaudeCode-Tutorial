מצאתם טעות? יש רעיון? ספרו לנו

הקורס הזה משתפר בזכות אנשים שמדווחים. כל דיווח — טעות בעברית, פקודה שלא עבדה, פרק לא ברור, או רעיון לתוכן חדש — עוזר לכל מי שילמד אחריכם.

איך שולחים

המשוב מתנהל דרך GitHub — אותה פלטפורמה שאתם ממילא לומדים בקורס. בחרו את הסוג המתאים:

⚠️ נדרש חשבון GitHub (חינם) שלושת הכפתורים למטה פותחים טופס באתר GitHub, ולכן צריך חשבון — פתיחתו חינמית ולוקחת שתי דקות: הנה מדריך צעד־אחר־צעד. אין לכם חשבון ולא מתחשק לפתוח? זה בסדר — הקורס עצמו פתוח לגמרי גם בלי.

✅ דיווח טוב בשלושה משפטים באיזה עמוד זה קרה, מה ציפיתם שיקרה, ומה קרה בפועל. אם זו בעיית תצוגה — ציינו גם דפדפן ומכשיר. זהו, זה כל מה שצריך.
💡 מרגישים אמיצים? שלחו תיקון בעצמכם הקורס הוא ריפו פתוח — ואתם הרי לומדים כאן בדיוק את זה. סיימתם את פרק 3? נסו את התהליך האמיתי: עשו fork, תקנו, ופתחו Pull Request. אין תרגיל טוב מזה, ואתם תופיעו ברשימת התורמים של הקורס.
