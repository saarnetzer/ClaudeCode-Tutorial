סוכנים אוטונומיים לגמרי — Agent SDK ועקרונות עבודה

בפרק הזה נבנה סוכן משלנו בקוד עם ה‑Claude Agent SDK — אותו מנוע שמריץ את Claude Code עצמו — ונלמד את חמשת העקרונות שמבדילים בין סוכן אוטונומי שמייצר ערך לבין כזה שמייצר בלגן.

מה נלמד בפרק

  • מה זה ה‑Claude Agent SDK ולמה הוא נקודת הזינוק הטובה ביותר
  • סוכן ראשון ב‑TypeScript וב‑Python
  • הוספת כלים מותאמים והרשאות מתוכנתות
  • חמשת עקרונות האוטונומיה הבטוחה
  • לאן ממשיכים מכאן

מה זה ה‑Agent SDK

ה‑Claude Agent SDK הוא ספרייה (ל‑TypeScript ול‑Python) שנותנת לכם בקוד את כל מה שמניע את Claude Code: הלולאה הסוכנית (חשיבה → כלי → תוצאה → חשיבה...), כלי הקבצים והטרמינל, מערכת ההרשאות, subagents,‏ hooks ו‑MCP. במקום לבנות תשתית סוכנים מאפס — אתם מקבלים את התשתית המוכחת ומרכיבים עליה את הסוכן שלכם: הלוגיקה, הגבולות, וההשתלבות במערכת שלכם.

# TypeScript
npm install @anthropic-ai/claude-agent-sdk

# Python
pip install claude-agent-sdk

סוכן ראשון: 20 שורות

TypeScript

agent.tsimport { query } from "@anthropic-ai/claude-agent-sdk";

const result = query({
  prompt: "מצא את כל קבצי ה-TODO בפרויקט וסכם אותם בקובץ TODO_REPORT.md",
  options: {
    cwd: "/path/to/project",
    allowedTools: ["Read", "Grep", "Glob", "Write"],
    maxTurns: 20,
  },
});

for await (const message of result) {
  if (message.type === "assistant") {
    console.log(message.message.content);   // לראות את הסוכן "חושב"
  }
  if (message.type === "result") {
    console.log("סיכום:", message.result);
    console.log("עלות ($):", message.total_cost_usd);
  }
}

Python

agent.pyimport anyio
from claude_agent_sdk import query, ClaudeAgentOptions

async def main():
    async for message in query(
        prompt="מצא את כל קבצי ה-TODO בפרויקט וסכם אותם בקובץ TODO_REPORT.md",
        options=ClaudeAgentOptions(
            cwd="/path/to/project",
            allowed_tools=["Read", "Grep", "Glob", "Write"],
            max_turns=20,
        ),
    ):
        print(message)

anyio.run(main)

הריצו — ותראו בפלט את הסוכן עובד: מחפש, קורא, כותב, ומחזיר תוצאה סופית עם עלות. זה סוכן אוטונומי אמיתי: נתתם מטרה, והוא בחר לבד את הצעדים.

כלי מותאם אישית

הכוח האמיתי: לתת לסוכן כלים מהעולם שלכם. כלים מותאמים מוגדרים כשרת MCP פנימי בתוך התהליך:

tools.tsimport { tool, createSdkMcpServer, query } from "@anthropic-ai/claude-agent-sdk";
import { z } from "zod";

const sendAlert = tool(
  "send_alert",
  "שולח התראה לצוות התפעול. השתמש רק לתקלות ברמת חומרה גבוהה.",
  { message: z.string(), severity: z.enum(["low", "high"]) },
  async (args) => {
    await notifyOps(args.message, args.severity);   // הלוגיקה שלכם
    return { content: [{ type: "text", text: "ההתראה נשלחה" }] };
  }
);

const opsServer = createSdkMcpServer({
  name: "ops-tools",
  tools: [sendAlert],
});

const result = query({
  prompt: "בדוק את הלוגים של הלילה. אם יש תקלה חמורה - שלח התראה",
  options: {
    mcpServers: { "ops-tools": opsServer },
    allowedTools: ["Read", "Grep", "mcp__ops-tools__send_alert"],
    maxTurns: 30,
  },
});

שימו לב לתיאור הכלי — "השתמש רק לתקלות חמורות". כמו ב‑Skills וב‑subagents, התיאור הוא הממשק בין הכוונה שלכם לשיקול הדעת של הסוכן. ואם רוצים שליטה קשיחה יותר: ה‑SDK תומך גם ב‑hooks וב‑canUseTool — פונקציה שלכם שמאשרת או דוחה כל קריאת כלי בזמן אמת, בקוד.

חמשת עקרונות האוטונומיה הבטוחה

כל מה שלמדתם בקורס מתנקז לחמישה עקרונות. סוכן שעומד בכולם — אפשר באמת לשחרר:

1. לולאת משוב שהסוכן מריץ בעצמו

אוטונומיה בלי דרך לבדוק הצלחה היא ניחוש. טסטים (פרק 3), דפדפן (פרק 7), קומפילציה, lint — הסוכן חייב כלי שאומר לו "הצלחת/נכשלת" בלי בן אדם. נסחו כל משימה עם קריטריון בדיקה: "...וסיימת רק כשכל הטסטים ירוקים".

2. גבולות בקוד, לא בהבטחות

הרשאות מינימום (allowedTools), ‏hooks חוסמים (פרק 6), משתמשי readonly (פרק 7), סביבה מבודדת (פרק 9). מה שאסור — שיהיה בלתי אפשרי, לא רק "לא מומלץ".

3. בלמים כמותיים

‏maxTurns לכל ריצה, ניטור עלות מה‑JSON שחוזר, ו‑timeout חיצוני. סוכן שתקוע בלולאה צריך להיעצר מעצמו — לא כשתשימו לב לחשבון.

4. זיכרון חיצוני ועבודה בפרוסות

משימות ארוכות מפרקים לשלבים שכל אחד נגמר בקומיט ובעדכון קובץ מצב (PROGRESS.md — פרק 4). ריצה שנקטעת ממשיכה מהקובץ, לא מאפס. git הוא עמוד השדרה: כל שלב הפיך.

5. אדם בנקודות ההכרעה

אוטונומיה "לגמרי" לא אומרת "בלי בני אדם" — אלא שהאדם עובר מהלולאה הפנימית לנקודות הביקורת: הסוכן עובד לבד שעות, אבל התוצר הוא PR שאתם מאשרים, והתראות (Notification hooks, ‏send_alert) מזעיקות אתכם כשמשהו חריג. אתם מנהלים, לא מלווים צמוד.

✅ המבחן הסופי לפני שמשחררים סוכן לרוץ לבד, שאלו: "מה הדבר הכי גרוע שיכול לקרות בריצה הזו?" אם התשובה היא "ענף git מבולגן שאמחק" — קדימה. אם התשובה כוללת מסד נתונים אמיתי, כסף או לקוחות — חסר עיקרון 2. חזרו לחזק גבולות.

תרגילים

תרגיל 10.1 הסוכן הראשון שלכם בקוד

הריצו את סוכן ה‑TODO מהדוגמה (בשפה שנוחה לכם) על פרויקט אמיתי. אחר כך שנו את המשימה למשהו שלכם: יצירת דוח תיעוד, איתור קוד מת, בדיקת עקביות תרגומים. עקבו בפלט אחרי הצעדים שהוא בוחר.

אם משהו נתקע

ודאו שמשתנה הסביבה ANTHROPIC_API_KEY מוגדר, ושה‑allowedTools כוללים את מה שהמשימה באמת דורשת (כתיבת דוח = צריך Write). שגיאת "כלי לא מורשה" בפלט היא רמז מדויק למה שחסר.

תרגיל 10.2 כלי מותאם + שיקול דעת

בנו סוכן "בודק בריאות פרויקט" עם כלי מותאם אחד: report_status(status, details) שכותב לקובץ JSON (או שולח הודעה אמיתית — טלגרם/סלאק אם תרצו). המשימה: "הרץ טסטים ו‑lint; דווח ok אם הכול תקין, ו‑failed עם פירוט אם לא". הריצו פעם על פרויקט תקין ופעם על שבור.

מה בודקים כאן

שהסוכן מפעיל את הכלי שלכם נכון: פעם אחת עם ok, פעם עם failed + פירוט אמיתי של הכשל. אם הוא מדווח ok על פרויקט שבור — חדדו את הפרומפט ("הרץ בפועל וקרא את הפלט; אל תניח"). ברוכים הבאים להנדסת סוכנים.

תרגיל 10.3 פרויקט גמר: הסוכן הלילי

חברו הכול: בנו סוכן שרץ מתוזמן (cron או GitHub Actions מתוזמן) פעם ביום על ריפו שלכם, ומבצע משימת תחזוקה לבחירתכם מקצה לקצה — על ענף נפרד, עם טסטים כלולאת משוב, maxTurns, קובץ מצב, ו‑PR כתוצר. תנו לו לרוץ שלושה לילות וסקרו את התוצרים.

מסגרת מומלצת

קחו את nightly-deps.sh מפרק 9 כשלד, והחליפו את המשימה: ניקוי קוד מת, שיפור כיסוי טסטים ("הוסף טסט אחד לקובץ הכי פחות מכוסה"), או עדכון תיעוד. עברו על חמשת העקרונות כ‑checklist לפני ההרצה הראשונה. אחרי שלושה לילות תדעו בדיוק מה לחזק — וזו בדיוק המיומנות של מהנדס סוכנים.

השלמתם את מסלול הסוכן הבודד 🎉

התחלתם מהתקנה של כלי טרמינל, ועכשיו אתם יודעים לתכנן, לבנות ולשחרר סוכן אוטונומי — עם גבולות נכונים, לולאות משוב ובקרה אנושית. נשארה מדרגה אחת: בשני הפרקים הבאים נעבור מסוכן בודד לצוות סוכנים שלם — קודם העקרונות והתבניות, ואחר כך דוגמאות מחמישה עולמות שונים.
