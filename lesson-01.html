מה זה Claude Code? התקנה והרצה ראשונה

בפרק הזה תבינו מה Claude Code בעצם עושה, תתקינו אותו על המחשב שלכם, ותוך רבע שעה תריצו את השיחה הראשונה שלכם — כזו שבאמת יוצרת קוד עובד.

מה נלמד בפרק

  • מה ההבדל בין Claude Code לבין צ'אט רגיל עם AI
  • התקנה על macOS / Linux / Windows
  • התחברות לחשבון והרצה ראשונה
  • שלוש דרכים לצאת, לעצור ולהתחיל מחדש

אז מה זה בעצם?

Claude Code הוא סוכן תכנות שרץ בטרמינל שלכם. ההבדל בינו לבין צ'אט רגיל (כמו אתר claude.ai) הוא עצום:

  • צ'אט רגיל מדבר על קוד — אתם מעתיקים ומדביקים בעצמכם.
  • Claude Code עושה: הוא קורא את הקבצים שלכם, כותב ועורך אותם, מריץ פקודות, מריץ טסטים, מתקן שגיאות שהוא רואה — ומתקדם צעד־צעד עד שהמשימה גמורה.

המילה החשובה כאן היא "סוכן" (Agent): תוכנה שמקבלת מטרה, מתכננת, מפעילה כלים (קריאת קבצים, טרמינל, חיפוש), בודקת את התוצאה של עצמה — וחוזרת על התהליך עד להצלחה. כל הקורס הזה הוא בעצם מסע: מלהשתמש בסוכן, ועד לבנות סוכנים משלכם שרצים לבד.

💡 לא רק לקוד אנשים משתמשים ב‑Claude Code גם לכתיבת מסמכים, ניתוח נתונים, אוטומציה של קבצים ועוד. אבל הבית הטבעי שלו הוא פרויקטי תוכנה — ושם נתמקד.

התקנה

macOS / Linux

curl -fsSL https://claude.ai/install.sh | bash

Windows (PowerShell)

irm https://claude.ai/install.ps1 | iex

או דרך npm (אם Node.js כבר מותקן אצלכם)

npm install -g @anthropic-ai/claude-code

בסיום, ודאו שההתקנה הצליחה:

claude --version

אם קיבלתם מספר גרסה — אתם מוכנים.

כך נראית ההרצה הראשונה (הדגמה):

demo: first-run

    
  



  

    ⚠️ הפקודה לא מזוהה?
    סגרו ופתחו מחדש את הטרמינל (או את PowerShell). סקריפט ההתקנה מוסיף את הכלי לנתיב המערכת, והשינוי נטען רק בחלון חדש.
  


  
הרצה ראשונה והתחברות

  
נכנסים לתיקייה של פרויקט (או לתיקייה ריקה לניסיון) ומריצים:

  
macOS / Linuxmkdir hello-claude && cd hello-claude
claude

  
Windows (PowerShell)mkdir hello-claude; cd hello-claude
claude

  
בהרצה הראשונה תתבקשו להתחבר. יש שתי אפשרויות:

  
    
    
  • מנוי Claude (Pro/Max) — התחברות דרך הדפדפן לחשבון claude.ai. הכי פשוט למשתמש פרטי.
    • 
    
  • מפתח API של Anthropic Console — תשלום לפי שימוש. מתאים לצוותים ולאוטומציה (נצטרך את זה בפרק 10).
    • 
  

  
אחרי ההתחברות תראו שורת קלט ממתינה. זה הכול — אתם בפנים. נסו לכתוב:

  
בנה לי דף HTML בודד בשם index.html עם משחק איקס-עיגול פשוט, בעברית, עם עיצוב נחמד

  
שימו לב מה קורה: Claude מציג לכם מה הוא מתכנן לעשות, ולפני כל פעולה "מסוכנת" (כתיבת קובץ, הרצת פקודה) הוא מבקש אישור. אשרו, וראו את הקובץ נוצר לנגד עיניכם. פתחו את index.html בדפדפן — יש לכם משחק.


  

    ✅ אפשר לכתוב בעברית
    Claude מבין עברית מצוין. את הדוגמאות בקורס נכתוב לפעמים בעברית ולפעמים באנגלית — שתיהן עובדות. בקוד עצמו מקובל להישאר באנגלית.
  


  
לצאת, לעצור, להמשיך

  

  

    
פעולהאיך

    
לעצור את Claude באמצע פעולהמקש Esc — עוצר מיד, ואפשר לתת הנחיה מתוקנת

    
לצאת מהשיחהCtrl+C פעמיים, או הפקודה /exit

    
להמשיך את השיחה האחרונהclaude --continue

    
לבחור שיחה ישנה מרשימהclaude --resume

  

  


  
תרגילים

  

    
תרגיל 1.1 התקנה ואימות

    
התקינו את Claude Code לפי מערכת ההפעלה שלכם, וודאו ש‑claude --version מחזיר מספר גרסה. אחר כך הריצו claude בתיקייה ריקה והשלימו את ההתחברות.

    
הצצה לפתרון
      
אם claude --version נכשל אחרי התקנה: פתחו טרמינל חדש. אם עדיין לא עובד ב‑npm — בדקו ש‑npm bin -g נמצא ב‑PATH שלכם. בהתקנת הסקריפט הרשמי זה מטופל אוטומטית.

    

  


  

    
תרגיל 1.2 הפרויקט הראשון שלכם

    
בתיקייה חדשה, בקשו מ‑Claude לבנות "דף אישי" — עמוד HTML אחד עם השם שלכם, תחומי עניין וכפתור שמחליף צבע רקע. פתחו את התוצאה בדפדפן. ואז — וזה החלק החשוב — בקשו שינוי: "הוסף מצב כהה שנשמר גם אחרי רענון".

    
הצצה לפתרון
      
הנקודה בתרגיל: לראות ש‑Claude Code זוכר את ההקשר. בבקשת השינוי לא צריך להסביר לו שוב מה יש בקובץ — הוא קורא אותו בעצמו ועורך רק את מה שצריך. לשמירת המצב הוא כנראה ישתמש ב‑localStorage. אם לא — בקשו במפורש.

    

  


  

    
תרגיל 1.3 עצירה באמצע

    
תנו ל‑Claude משימה גדולה בכוונה ("בנה אתר שלם עם 5 עמודים...") ובאמצע העבודה לחצו Esc. שנו כיוון: "בעצם עמוד אחד מספיק, אבל תוסיף טופס יצירת קשר". שימו לב איך הוא מסתגל בלי להתחיל מאפס.

    
הצצה לפתרון
      
Esc הוא אחד הכלים החשובים ביותר בעבודה שוטפת: זול יותר לעצור ולכוון מחדש מאשר לתת ל‑Claude לסיים כיוון שגוי ואז לתקן. סוכן טוב = משוב מוקדם.
