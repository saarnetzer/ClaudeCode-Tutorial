# פרויקט התרגול של קורס Claude Code

אפליקציית רשימת משימות קטנה — עם **שלושה באגים שהוטמנו בכוונה**. זו נקודת הפתיחה
האחידה לתרגילי הקורס: פתחו כאן את Claude Code ותנו לו לעבוד.

## איך מתחילים

1. פתחו טרמינל בתיקייה הזו והריצו `claude`
2. פתחו את `index.html` בדפדפן ושחקו עם האפליקציה — נסו להוסיף, לסמן, למחוק ולרענן
3. משהו לא עובד? מצוין. ככה זה אמור להיות

## מה שבור (בלי ספוילרים על המיקום)

- **באג 1:** כפתור "מחק" לא מוחק את המשימה
- **באג 2:** מונה המשימות הפתוחות לא מתעדכן אף פעם
- **באג 3:** המשימות נעלמות אחרי רענון הדף, למרות שיש קוד שמירה

## תרגילים מומלצים

- **פרק 2:** בקשו מ-Claude לתקן את הבאגים — פעם בניסוח כללי ("תתקן את הבאג") ופעם
  בניסוח מדויק (תיאור התופעה המלאה). השוו תהליך ותוצאה
- **פרק 2 (Plan Mode):** בקשו תוכנית לתיקון שלושת הבאגים לפני שנוגעים בקוד
- **פרק 3:** אתחלו כאן ריפו git, ותקנו כל באג בקומיט נפרד עם הודעה מסודרת
- **פרק 8:** שלחו את code-reviewer למצוא את הבאגים לבד — בלי לספר לו מה שבור

בהצלחה! 🚀
