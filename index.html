ההתקדמות שלכם

התעודה נוצרת אצלכם בדפדפן, עם השם שתבחרו — מוכנה לשיתוף בלינקדאין.

מה צריך לפני שמתחילים?

  • מחשב עם macOS, Linux או Windows.
  • היכרות בסיסית עם הטרמינל (לפתוח, להקליד פקודה, Enter). זהו. מעולם לא פתחתם טרמינל? יש לנו מדריך צעד־אחר־צעד למי שמתחיל מאפס — רבע שעה ואתם מוכנים.
  • חשבון Claude (מנוי Pro/Max) או מפתח API מ‑Anthropic Console.
  • מפרק 3 והלאה: ‏Git מותקן וחשבון GitHub (חינם). גם כאן — אין ידע מוקדם? יש מדריך הקמה צעד־אחר־צעד.
  • לא צריך להיות מתכנתים מקצועיים — הקורס בנוי מהיסודות, וכל מושג מוסבר ברגע שהוא מופיע.

תוכן הקורס

1 מה זה Claude Code? התקנה והרצה ראשונה מה הכלי הזה בכלל עושה, איך מתקינים, מתחברים, ומריצים שיחה ראשונה שבאמת עושה משהו. ~20 דק' 2 יסודות העבודה היומיומית איך מנסחים בקשות טובות, איך Claude קורא ועורך קבצים, מצבי הרשאות, ופקודות שחייבים להכיר. ~30 דק' 3 עבודה עם Git ו‑GitHub קומיטים, ענפים, פתרון קונפליקטים ו‑Pull Requests — הכול בשפה חופשית, בלי לשנן פקודות git. ~25 דק' 4 זיכרון והקשר: CLAUDE.md וניהול קונטקסט איך מלמדים את Claude את הפרויקט שלכם פעם אחת, ואיך שומרים על שיחות ממוקדות ויעילות. ~25 דק' 5 פקודות מותאמות אישית ו‑Skills הופכים משימות שחוזרות על עצמן לפקודת Slash אחת, ובונים "מיומנויות" ש‑Claude שולף לבד בזמן הנכון. ~30 דק' 6 Hooks — אוטומציה של תהליך העבודה קוד שרץ אוטומטית לפני או אחרי כל פעולה של Claude: פורמט אוטומטי, חסימות בטיחות, התראות. ~30 דק' 7 MCP — מחברים את Claude לעולם נותנים ל‑Claude כלים חדשים: דפדפן, מסדי נתונים, Slack ועוד — דרך פרוטוקול ה‑MCP. ~30 דק' 8 Subagents — צוות של סוכני משנה בונים סוכנים מתמחים (בודק קוד, כותב טסטים, חוקר) ש‑Claude מפעיל בעצמו כשצריך. ~30 דק' 9 לשלוט במה שמותר — אבטחה בעבודה עם סוכן כללי allow/deny, הגנה על סודות, הזרקת פרומפט ומתי חייבים סנדבוקס — הבלמים שלומדים לפני שמורידים ידיים מההגה. ~30 דק' 10 מצב Headless ואוטומציה ב‑CI מריצים את Claude בלי מסך אינטראקטיבי: סקריפטים, GitHub Actions, ותיוג @claude ב‑Pull Requests. ~35 דק' 11 סוכנים אוטונומיים לגמרי — Agent SDK ועקרונות עבודה בונים סוכן משלכם עם ה‑Claude Agent SDK, ולומדים את העקרונות שמאפשרים לתת לו לרוץ לבד — בבטחה. ~45 דק' 12 יצירת צוות סוכנים — עקרונות, תבניות ותשתית מסוכן בודד לצוות שלם: תפקידים, חוזי תוצרים, ושלוש תבניות ארגון — פס ייצור, מנהל־ועובדים ועבודה במקביל. ~40 דק' 13 צוותי סוכנים מעולמות שונים — חמש דוגמאות מהחיים צוות פיתוח, מערכת מגזין, צוות נתונים, משמרת לילה תפעולית וצוות תמיכה — הרכב, כלים ולקחים לכל אחד. ~45 דק'

איך ללמוד נכון מהקורס הזה

  1. עושים, לא רק קוראים. כל פרק כולל תרגילים — פתחו טרמינל לצד הדפדפן ובצעו אותם באמת. המיומנות נקנית בעשייה.
  2. לפי הסדר. הפרקים בנויים זה על זה: פרק 13 מניח שאתם שולטים בכל מה שלפניו.
  3. פתרון רק אחרי ניסיון. לכל תרגיל מצורף פתרון מוסתר — הציצו בו רק אחרי שניסיתם לבד.
  4. סמנו התקדמות. בסוף כל פרק יש כפתור "הושלם" — הוא שומר את ההתקדמות בדפדפן שלכם.
