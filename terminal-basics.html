הטרמינל למתחילים גמורים — צעד אחר צעד

אף פעם לא פתחתם טרמינל? מצוין, התחלתם במקום הנכון. בעמוד הזה תלמדו מה זה בכלל טרמינל, איך פותחים אותו במחשב שלכם, ואת חמש הפקודות היחידות שצריך בשביל הקורס. רבע שעה — ואתם מוכנים לפרק 1.

מה זה בכלל טרמינל?

טרמינל (נקרא גם "שורת פקודה" או Command Line) הוא דרך לדבר עם המחשב בטקסט במקום בעכבר: כותבים פקודה, לוחצים Enter, והמחשב מבצע ומדפיס תשובה. זה נראה ככה:

$ echo שלום
שלום

הסימן $ (או > ב‑Windows) הוא ה"פרומפט" — סימן שהטרמינל מחכה לפקודה שלכם. אתם לא מקלידים אותו — רק את מה שאחריו.

💡 למה בכלל צריך את זה? Claude Code רץ בתוך הטרמינל. אבל אל דאגה — אתם צריכים לדעת רק לפתוח אותו, להגיע לתיקייה ולהריץ פקודה. את כל השאר Claude יעשה בשבילכם.

שלב 1: פותחים את הטרמינל

🪟 Windows

  1. לחצו על מקש ⊞ Win (מקש החלונות במקלדת).
  2. הקלידו terminal ולחצו Enter.
  3. נפתח חלון בשם Windows Terminal (או PowerShell) — זה הטרמינל שלכם.

אין לכם Windows Terminal (ב‑Windows 10 ישן למשל)? התקינו אותו בחינם מ‑חנות Microsoft (aka.ms/terminal), או הקלידו powershell במקום — גם זה עובד מצוין.

🍎 macOS (מק)

  1. לחצו Cmd+רווח לפתיחת חיפוש Spotlight.
  2. הקלידו terminal ולחצו Enter.
  3. נפתח חלון לבן/שחור עם שורת טקסט — זהו.

אפשר גם דרך Finder: יישומים ← כלי עזר ← Terminal. המדריך הרשמי של Apple נמצא כאן.

🐧 Linux

  1. ברוב ההפצות (Ubuntu, Fedora...): קיצור Ctrl+Alt+T.
  2. או חפשו terminal בתפריט היישומים.

מדריך מתחילים מצוין באנגלית יש באתר של Ubuntu.

✅ בדיקה שהכול עובד בטרמינל שפתחתם, הקלידו echo hello ולחצו Enter. אם המחשב הדפיס בחזרה hello — הטרמינל שלכם עובד ואתם רשמית משתמשי שורת פקודה.

שלב 2: חמש הפקודות שבאמת צריך

הטרמינל תמיד "עומד" בתוך תיקייה כלשהי במחשב — כמו חלון סייר קבצים, רק בטקסט. הפקודות האלה מזיזות אתכם בין תיקיות:

פקודהמה היא עושהדוגמה
pwdמציגה באיזו תיקייה אתם עכשיו (ב‑Windows: החלון מציג את זה בפרומפט)pwd
ls (ב‑Windows גם dir)מציגה מה יש בתיקייה הנוכחיתls
cdעוברת לתיקייה אחרת (change directory)cd Documents
cd ..עולה תיקייה אחת אחורהcd ..
mkdirיוצרת תיקייה חדשהmkdir my-project

נסו את זה ברצף — צרו תיקייה לקורס והיכנסו אליה:

mkdir claude-course
cd claude-course
pwd

אם pwd (או הפרומפט) מראה נתיב שמסתיים ב‑claude-course — עשיתם הכול נכון.

שלב 3: טריקים שחוסכים חיים

  • Tab — השלמה אוטומטית. הקלידו את תחילת שם תיקייה ולחצו Tab, והטרמינל ישלים לבד. משתמשים בזה כל הזמן.
  • ↑ (חץ למעלה) — מחזיר את הפקודה הקודמת. אין צורך להקליד שוב.
  • Ctrl+C — עוצר פקודה שנתקעה או רצה יותר מדי זמן. כפתור החירום שלכם.
  • clear (ב‑Windows גם cls) — מנקה את המסך כשנהיה עמוס.
  • הדבקה: ב‑Windows וב‑Linux לרוב Ctrl+Shift+V (או קליק ימני), במק Cmd+V כרגיל.
⚠️ קיבלתם הודעת שגיאה? זה קורה לכולם, כל יום. שגיאות בטרמינל הן טקסט שנועד לעזור — קראו אותן. הנפוצה ביותר: command not found = שגיאת הקלדה או שהתוכנה לא מותקנת. ו‑No such file or directory = שם תיקייה שגוי (בדקו עם ls מה יש באמת).
