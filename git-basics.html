Git ו-GitHub מאפס — התקנה, חשבון וחיבור

פרק 3 מניח שיש לכם Git מותקן וחשבון GitHub. אין לכם? העמוד הזה מסדר את זה ברבע שעה, צעד אחר צעד — ומההתקנה הזו והלאה, את פקודות ה-git עצמן כבר לא תצטרכו לשנן: Claude יריץ אותן בשבילכם.

קודם כול: מה זה בכלל, ומה ההבדל?

  • Git היא תוכנה שרצה על המחשב שלכם ושומרת "נקודות שמירה" (קומיטים) של הפרויקט. כמו שמירה במשחק: אפשר תמיד לחזור אחורה. היא עובדת גם בלי אינטרנט ובלי שום חשבון.
  • GitHub הוא אתר (בבעלות Microsoft) שמאחסן עותק של הפרויקט בענן: גיבוי, שיתוף עם אחרים, ו-Pull Requests. בשבילו כן צריך חשבון.

במילים אחרות: Git = מנוע השמירה במחשב, GitHub = הענן שמעליו. לקורס צריך את שניהם — Git כבר מפרק 3, ו-GitHub לחלק מהתרגילים ולפרק 10.

💡 למה זה חשוב דווקא בקורס על סוכנים? כשסוכן AI עורך עשרות קבצים בשבילכם, Git הוא רשת הביטחון: כל שינוי נרשם, וכל טעות הפיכה ב-10 שניות. זו הסיבה שפרק 3 מגיע כל כך מוקדם בקורס.

שלב 1: מתקינים Git

ייתכן שהוא כבר מותקן אצלכם — בדקו קודם בטרמינל:

git --version

קיבלתם מספר גרסה? דלגו לשלב 2. קיבלתם "command not found"? מתקינים:

🪟 Windows

PowerShellwinget install --id Git.Git -e

או הורידו את המתקין מהאתר הרשמי: git-scm.com/download/win (לחצו "הבא" על כל ברירות המחדל — הן טובות). בסיום סגרו ופתחו מחדש את הטרמינל.

🍎 macOS

xcode-select --install

זה מתקין את כלי הפיתוח של Apple, ש-Git כלול בהם. חלופה למי שמשתמש ב-Homebrew: ‏brew install git.

🐧 Linux

sudo apt install git      # Ubuntu / Debian
sudo dnf install git      # Fedora
✅ בדיקה פתחו טרמינל חדש והריצו git --version. מספר גרסה = מותקן. הלאה.

שלב 2: מציגים את עצמכם ל-Git

‏Git חותם כל נקודת שמירה בשם ובאימייל. הגדירו אותם פעם אחת (בכל מערכת הפעלה, אותן פקודות):

git config --global user.name "השם שלכם"
git config --global user.email "you@example.com"

השתמשו באותו אימייל שתפתחו איתו את חשבון GitHub בשלב הבא — כך התרומות שלכם יזוהו נכון.

שלב 3: פותחים חשבון GitHub (חינם)

  1. גשו אל github.com/signup.
  2. הזינו אימייל (זה מהשלב הקודם), בחרו סיסמה חזקה, ובחרו שם משתמש.
  3. אשרו את קוד האימות שיישלח לאימייל — וזהו, יש לכם חשבון.
⚠️ רגע לפני שבוחרים שם משתמש שם המשתמש יופיע בכתובת של כל פרויקט שתפרסמו (למשל github.com/your-name) — והוא גם קורות החיים הציבוריים שלכם כמפתחים. בחרו משהו מקצועי שתשמחו לראות גם בעוד חמש שנים; באנגלית, קצר, בלי מספרים אקראיים.

מומלץ בחום: הפעילו אימות דו-שלבי (2FA) — בהגדרות החשבון: ‏Settings ← Password and authentication ← Two-factor authentication. חמש דקות שמגינות על כל הקוד שלכם.

שלב 4: מחברים את המחשב לחשבון

הדרך הנוחה ביותר — וזו שהקורס משתמש בה — היא GitHub CLI (הפקודה gh):

התקנה

Windows (PowerShell)winget install --id GitHub.cli -e
macOSbrew install gh
Linuxsudo apt install gh   # או לפי ההוראות ב-cli.github.com

התחברות (פעם אחת)

gh auth login

עונים על השאלות כך: ‏GitHub.com ← ‏HTTPS ← ‏Login with a web browser. יופיע קוד בן 8 תווים — העתיקו אותו, אשרו בדפדפן שנפתח, וזהו.

✅ בדיקה סופית שהכול מחובר הריצו gh auth status. אם אתם רואים ✓ ליד שם המשתמש שלכם — המחשב מחובר לחשבון, ואתם מוכנים לחלוטין לפרק 3, כולל תרגיל ה-Pull Request.

זהו — אתם מסודרים

שימו לב מה לא עשינו כאן: לא למדנו אף פקודת git מעבר ל-config. זה בכוונה — בפרק 3 תגלו שאת כל העבודה השוטפת (קומיטים, ענפים, שחזורים, PRs) מבקשים מ-Claude במילים חופשיות, והוא מריץ את הפקודות הנכונות. התשתית שבניתם עכשיו היא כל מה שהיה חסר.
