צ'יט-שיט: כל מה שצריך, בעמוד אחד

כל הפקודות, הקיצורים והמיקומים מהקורס — מרוכזים לשליפה מהירה. שמרו את העמוד בסימניות.

🚀 התקנה והרצה

curl -fsSL https://claude.ai/install.sh | bashהתקנה macOS / Linux
irm https://claude.ai/install.ps1 | iexהתקנה Windows
claude --versionאימות התקנה
claudeפתיחת שיחה בתיקייה הנוכחית
claude --continueהמשך השיחה האחרונה
claude --resumeבחירת שיחה ישנה מרשימה

🔌 MCP

claude mcp add שם -- פקודהחיבור שרת חדש
claude mcp add --scope project ...שרת משותף לצוות (.mcp.json)
claude mcp listשרתים מחוברים ומצבם
claude mcp get שםפרטי שרת
claude mcp remove שםהסרת שרת
npx @playwright/mcp@latestשרת דפדפן (Playwright)

🤖 מצב Headless ואוטומציה

claude -p "שאלה"ריצה חד-פעמית ללא ממשק
--output-format jsonפלט מובנה לסקריפטים
--allowedTools "Bash(npm test),Read"אישור מראש לכלים ספציפיים
--max-turns 15תקרת צעדים לריצה
--dangerously-skip-permissionsביטול אישורים — רק בסביבה מבודדת!
cat file | claude -p "..."הזרמת קלט (Windows: ‏Get-Content)

🪝 אירועי Hooks

PreToolUseלפני כלי — חסימות (exit 2 = חסום והסבר)
PostToolUseאחרי כלי — פורמט, lint, לוג
UserPromptSubmitעם שליחת הודעה
Stopכש-Claude מסיים (exit 2 = תמשיך לעבוד)
Notificationכש-Claude ממתין לכם — התראות

🧩 תבנית Subagent

.claude/agents/name.md---
name: my-agent
description: מה הוא עושה ומתי
  להפעיל אותו (זה מה שקובע!)
tools: Read, Grep, Glob
---

ה-system prompt המלא:
תפקיד, תהליך צעד-צעד,
ומה להחזיר בסוף.

🔒 אבטחה: allow / deny

.claude/settings.json{
  "permissions": {
    "allow": ["Bash(npm test)"],
    "deny": [
      "Read(./.env)",
      "Read(./secrets/**)",
      "Bash(rm -rf:*)"
    ]
  }
}

‏deny גובר על allow. ההסבר המלא בפרק 9

🛡️ חמשת עקרונות האוטונומיה

  1. לולאת משוב שהסוכן מריץ בעצמו
  2. גבולות בקוד, לא בהבטחות
  3. בלמים כמותיים (turns, עלות, timeout)
  4. זיכרון חיצוני ועבודה בפרוסות
  5. אדם בנקודות ההכרעה
