What you need before starting

  • A computer running macOS, Linux, or Windows.
  • Basic familiarity with the terminal (open it, type a command, Enter). That's it. Never opened a terminal? We have a step-by-step guide for absolute beginners — fifteen minutes and you're ready.
  • A Claude account (Pro/Max subscription) or an API key from the Anthropic Console.
  • From Lesson 3 onward: Git installed and a free GitHub account. New to those too? There's a step-by-step setup guide.
  • You don't need to be a professional programmer — the course is built from the ground up, and every concept is explained the moment it appears.

How to get the most out of this course

  1. Do, don't just read. Every lesson has exercises — open a terminal next to the browser and actually run them. Skill is earned by doing.
  2. In order. The lessons build on each other: Lesson 13 assumes you've mastered everything before it.
  3. Solutions only after trying. Every exercise has a hidden solution — peek only after a real attempt.
  4. Track your progress. Each lesson ends with a "complete" button — it saves your progress in this browser.
🧪 Ready-made practice project Want a common starting point for the exercises? Download the practice project — a small task-list app with three planted bugs, used by exercises from Lesson 2 onward. There's also a live preview.
