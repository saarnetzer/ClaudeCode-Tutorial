Feedback

Found a mistake? Got an idea? Tell us

This course improves because people report things. Every report — a typo, a command that didn't work, an unclear lesson, or an idea for new content — helps everyone who learns after you.

How to send it

Feedback runs through GitHub — the same platform you're learning about in this course anyway. Pick the right type:

⚠️ A free GitHub account is required The three buttons below open a form on GitHub, so you need an account — it's free and takes two minutes: here's a step-by-step guide. Don't have one and don't feel like signing up? That's fine — the course itself is completely open without it.

🐛 Report an issue

A content mistake, a broken link, a command that doesn't work, a display problem.

Open a report →

💡 Suggest an improvement

A missing topic, a lesson worth expanding, a reference tool you'd want.

💬 Everything else

A question, a thank you, a success story — all welcome.

Start a discussion →

✅ A good report in three sentences Which page it happened on, what you expected to happen, and what actually happened. If it's a display issue — mention your browser and device too. That's all it takes.
💡 Feeling brave? Send the fix yourself The course is an open repo — and this is exactly what you're learning here. Finished Lesson 3? Try the real thing: fork it, fix it, and open a Pull Request. There's no better exercise, and you'll appear in the course's contributor list.
