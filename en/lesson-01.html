What is Claude Code? Install and first run

In this lesson you'll understand what Claude Code actually does, install it on your machine, and within fifteen minutes run your first conversation — one that really produces working code.

What you'll learn

  • How Claude Code differs from a regular AI chat
  • Installing on macOS / Linux / Windows
  • Signing in and running for the first time
  • Three ways to exit, stop, and start over

So what is it, really?

Claude Code is a coding agent that runs in your terminal. The difference between it and a regular chat (like the claude.ai website) is huge:

  • A regular chat talks about code — you copy and paste it yourself.
  • Claude Code does: it reads your files, writes and edits them, runs commands, runs tests, fixes the errors it sees — and keeps going, step by step, until the job is done.

The key word here is "agent": software that takes a goal, plans, uses tools (reading files, the terminal, search), checks its own results — and repeats until it succeeds. This whole course is really a journey: from using an agent, to building agents of your own that run on their own.

💡 Not just for code People use Claude Code for writing documents, analyzing data, automating files and more. But its natural home is software projects — and that's where we'll focus.

Installation

macOS / Linux

curl -fsSL https://claude.ai/install.sh | bash

Windows (PowerShell)

irm https://claude.ai/install.ps1 | iex

Or via npm (if you already have Node.js)

npm install -g @anthropic-ai/claude-code

When it finishes, verify the install:

claude --version

If you got a version number — you're ready.

⚠️ Command not recognized? Close and reopen your terminal (or PowerShell). The installer adds the tool to your system path, and the change only loads in a new window.

First run and signing in

Enter a project folder (or an empty one, just to try) and run:

macOS / Linuxmkdir hello-claude && cd hello-claude
claude
Windows (PowerShell)mkdir hello-claude; cd hello-claude
claude

Here's what the first run looks like (demo):

demo: first-run

    
  

  
On first run you'll be asked to sign in. There are two options:

  
    
    
  • A Claude subscription (Pro/Max) — sign in through the browser with your claude.ai account. Simplest for individuals.
    • 
    
  • An Anthropic Console API key — pay per use. Suited to teams and automation (we'll need it in Lesson 11).
    • 
  

  
After signing in you'll see an input line waiting. That's it — you're in. Try typing:

  
build a single HTML page named index.html with a simple tic-tac-toe game and nice styling

  
Watch what happens: Claude shows you what it plans to do, and before every "risky" action (writing a file, running a command) it asks for approval. Approve, and watch the file appear before your eyes. Open index.html in a browser — you have a game.


  

    ✅ Any language works
    Claude understands requests in any language you're comfortable with. Code itself conventionally stays in English.
  


  
Exit, stop, resume

  

  

    
ActionHow

    
Stop Claude mid-actionEsc — stops immediately; you can give a corrected instruction

    
Exit the conversationCtrl+C twice, or the /exit command

    
Resume the last conversationclaude --continue

    
Pick an older conversation from a listclaude --resume

  

  


  
Exercises

  

    
Exercise 1.1 Install and verify

    
Install Claude Code for your operating system and make sure claude --version returns a version number. Then run claude in an empty folder and complete the sign-in.

    
Peek at the solution
      
If claude --version fails right after installing: open a new terminal. If it still fails with npm — check that npm bin -g is on your PATH. The official install script handles this automatically.

    

  


  

    
Exercise 1.2 Your first project

    
In a new folder, ask Claude to build a "personal page" — one HTML page with your name, interests, and a button that changes the background color. Open the result in a browser. Then — and this is the important part — ask for a change: "add a dark mode that survives page refresh".

    
Peek at the solution
      
The point of this exercise: seeing that Claude Code remembers context. In the change request you don't need to re-explain what's in the file — it reads it itself and edits only what's needed. For persistence it will probably use localStorage. If not — ask explicitly.

    

  


  

    
Exercise 1.3 Stopping mid-flight

    
Deliberately give Claude a big task ("build a full site with 5 pages...") and press Esc mid-work. Change direction: "actually one page is enough, but add a contact form". Notice how it adapts without starting over.

    
Peek at the solution
      
Esc is one of the most important tools in daily work: stopping and re-aiming is cheaper than letting Claude finish in the wrong direction and then fixing. A good agent = early feedback.
