Cheat sheet: everything you need, on one page

All the commands, shortcuts and locations from the course — collected for fast lookup. Bookmark this page.

🚀 Install and run

curl -fsSL https://claude.ai/install.sh | bashInstall on macOS / Linux
irm https://claude.ai/install.ps1 | iexInstall on Windows
claude --versionVerify the install
claudeStart a conversation in the current folder
claude --continueResume the last conversation
claude --resumePick an older conversation from a list

⌨️ Keys

EscStop Claude mid-action
Shift+TabSwitch permission mode (normal / auto-accept / Plan)
Ctrl+C twiceExit the conversation
TabAutocomplete in the terminal
↑Previous terminal command

🔒 Security: allow / deny

.claude/settings.json{
  "permissions": {
    "allow": ["Bash(npm test)"],
    "deny": [
      "Read(./.env)",
      "Read(./secrets/**)",
      "Bash(rm -rf:*)"
    ]
  }
}

deny beats allow. Full explanation in Lesson 9

🔌 MCP

claude mcp add name -- commandConnect a new server
claude mcp add --scope project ...Team-shared server (.mcp.json)
claude mcp listConnected servers and status
claude mcp get nameServer details
claude mcp remove nameRemove a server
npx @playwright/mcp@latestBrowser server (Playwright)

🤖 Headless mode and automation

claude -p "question"One-shot run, no interface
--output-format jsonStructured output for scripts
--allowedTools "Bash(npm test),Read"Pre-approve specific tools
--max-turns 15Turn cap per run
--dangerously-skip-permissionsDisable approvals — isolated environments only!
cat file | claude -p "..."Pipe input (Windows: Get-Content)

🪝 Hook events

PreToolUseBefore a tool — blocks (exit 2 = block + explain)
PostToolUseAfter a tool — format, lint, log
UserPromptSubmitWhen you send a message
StopWhen Claude finishes (exit 2 = keep working)
NotificationWhen Claude is waiting for you

🧩 Subagent template

.claude/agents/name.md---
name: my-agent
description: what it does and when
  to trigger it (this is what matters!)
tools: Read, Grep, Glob
---

The full system prompt:
role, step-by-step process,
and what to return at the end.

🛡️ The five autonomy principles

  1. A feedback loop the agent runs itself
  2. Boundaries in code, not promises
  3. Quantitative brakes (turns, cost, timeout)
  4. External memory and slice-based work
  5. A human at the decision points
