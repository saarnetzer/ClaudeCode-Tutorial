The terminal, step by step — for anyone starting from zero

Never opened a terminal? You're in the right place. This page covers what a terminal even is, how to open it on your machine, and the only five commands this course needs. Fifteen minutes — and you're ready for Lesson 1.

What is a terminal, anyway?

A terminal (also called the "command line") is a way to talk to your computer in text instead of with a mouse: you type a command, press Enter, and the computer runs it and prints an answer. It looks like this:

$ echo hello
hello

The $ sign (or > on Windows) is the "prompt" — a sign the terminal is waiting for your command. You don't type it — only what comes after it.

💡 Why do I even need this? Claude Code runs inside the terminal. But don't worry — you only need to know how to open it, get to a folder and run a command. Claude does everything else for you.

Step 1: open the terminal

🪟 Windows

  1. Press the ⊞ Win key.
  2. Type terminal and press Enter.
  3. A window named Windows Terminal (or PowerShell) opens — that's your terminal.

Don't have Windows Terminal (on older Windows 10, say)? Install it free from the Microsoft Store (aka.ms/terminal), or type powershell instead — that works fine too.

🍎 macOS

  1. Press Cmd+Space to open Spotlight search.
  2. Type terminal and press Enter.
  3. A window with a line of text opens — that's it.

You can also go through Finder: Applications → Utilities → Terminal. Apple's official guide is here.

🐧 Linux

  1. On most distributions (Ubuntu, Fedora...): Ctrl+Alt+T.
  2. Or search for terminal in the applications menu.

There's an excellent beginner guide on Ubuntu's site.

✅ Check that it works In the terminal you just opened, type echo hello and press Enter. If the computer printed back hello — your terminal works, and you're already a command-line user.

Step 2: the five commands you actually need

The terminal always "stands" inside some folder on your computer — like a file-explorer window, only in text. These commands move you between folders:

CommandWhat it doesExample
pwdShows which folder you're in (on Windows the prompt shows it)pwd
ls (Windows also dir)Shows what's in the current folderls
cdMoves to another folder (change directory)cd Documents
cd ..Goes up one foldercd ..
mkdirCreates a new foldermkdir my-project

Good news: every command in that table works as-is in Windows PowerShell too.

Try it in sequence — create a folder for the course and enter it (identical on every OS):

mkdir claude-course
cd claude-course
pwd

If pwd (or the prompt) shows a path ending in claude-course — you did it all correctly.

Step 3: shortcuts that save time

  • Tab — autocomplete. Type the start of a folder name and press Tab, and the terminal completes it. You'll use this constantly.
  • ↑ (up arrow) — brings back the previous command. No need to retype.
  • Ctrl+C — stops a command that's stuck or running too long. Your emergency key.
  • clear (Windows also cls) — clears the screen when it fills up.
  • Pasting: on Windows and Linux usually Ctrl+Shift+V (or right-click), on Mac Cmd+V as usual.
⚠️ Got an error message? It happens to everyone, every day. Terminal errors are text meant to help — read them. The most common: command not found = a typo or the software isn't installed. And No such file or directory = a wrong folder name (check with ls what's actually there).

That's it — you're ready

That really is all you need. You know how to open a terminal, navigate to a folder, and run a command. We'll install Claude Code itself together, one command, at the start of Lesson 1.
