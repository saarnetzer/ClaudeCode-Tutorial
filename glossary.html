מילון מונחים

כל המונחים מהקורס במקום אחד, בהסבר של שורה-שתיים. לצד כל מונח — הפרק שבו הוא מוסבר לעומק.

סוכן (Agent)
תוכנה שמקבלת מטרה, מתכננת, מפעילה כלים, בודקת את התוצאה של עצמה — וחוזרת על התהליך עד להצלחה. פרק 1
טרמינל / שורת פקודה (Terminal / CLI)
ממשק טקסטואלי לעבודה מול המחשב: מקלידים פקודה, מקבלים תשובה. הבית של Claude Code. מדריך הטרמינל
חלון הקשר (Context Window)
"זיכרון העבודה" של שיחה: כל מה שנאמר, נקרא והורץ. מוגבל בגודלו — ולכן מנהלים אותו במודע. פרק 4
טוקן (Token)
יחידת הטקסט שמודל שפה מעבד (בערך שלושת-רבעי מילה). ההקשר והעלות נמדדים בטוקנים. פרק 4
CLAUDE.md
קובץ הזיכרון של הפרויקט — נטען אוטומטית בתחילת כל שיחה. מה שכתוב בו, Claude פשוט יודע. פרק 4
Plan Mode
מצב שבו Claude רק קורא וחוקר — אסור לו לשנות דבר — ומציג תוכנית לאישורכם לפני ביצוע. פרק 2
פקודת Slash מותאמת (Custom Command)
קובץ Markdown ב-.claude/commands/ שהופך פרומפט שלם לפקודה של מילה אחת. פרק 5
Skill
חבילת ידע ש-Claude טוען בעצמו כשהמשימה מתאימה — לפי ה-description שלה. אתם לא צריכים לזכור לבקש. פרק 5
Hook
פקודה שלכם שרצה אוטומטית סביב פעולות של Claude — לאכיפת איכות, חסימת סכנות והתראות. מנגנון, לא בקשה. פרק 6
MCP‏ (Model Context Protocol)
פרוטוקול פתוח שמחבר ל-Claude כלים חיצוניים: דפדפן, מסדי נתונים, Slack ועוד. "שקע ה-USB" של הסוכנים. פרק 7
Subagent (סוכן משנה)
סוכן מתמחה עם הנחיות, כלים והקשר נפרדים, שהסוכן הראשי מפעיל כשמשימה מתאימה לו. פרק 8
מצב Headless
הרצת Claude כפקודה חד-פעמית ללא ממשק (claude -p) — הבסיס לסקריפטים ואוטומציה. פרק 9
CI‏ (Continuous Integration)
תהליך אוטומטי שרץ על כל שינוי קוד בריפו — בדיקות, בנייה, ואצלנו גם סוכני Claude. פרק 9
Agent SDK
ספריית TypeScript/Python שנותנת בקוד את המנוע של Claude Code — לבניית סוכנים וצוותים משלכם. פרק 10
לולאת משוב (Feedback Loop)
כלי שמאפשר לסוכן לבדוק את עצמו: טסטים, דפדפן, קומפילציה. בלעדיה — אוטונומיה היא ניחוש. פרק 10
צוות סוכנים (Agent Squad)
קבוצת סוכנים עם תפקידים מוגדרים, מתאם, זיכרון משותף וחוזי תוצרים — שעובדים יחד על מטרה אחת. פרק 11
מתאם (Orchestrator)
הגורם שמפרק מטרה למשימות, מאציל למומחים ומאחד את התוצרים — השיחה הראשית או סקריפט SDK. פרק 11
חוזה תוצרים
הגדרה מדויקת של מה כל סוכן בצוות מקבל ומה הוא מחזיר. הנקודה שבה צוותים נכשלים — או מצליחים. פרק 11
Git Worktree
עותק עבודה נוסף של אותו ריפו בתיקייה נפרדת — מאפשר לכמה סוכנים לעבוד במקביל בלי לדרוך זה על זה. פרק 11
GitHub
אתר שמאחסן מאגרי git (ריפוזיטוריז) בענן: גיבוי, שיתוף, ו-Pull Requests. ‏Git היא התוכנה במחשב — GitHub הוא הענן שמעליה. מדריך ההקמה
GitHub CLI‏ (gh)
כלי שורת הפקודה הרשמי של GitHub. אחרי ‎gh auth login חד-פעמי, Claude יכול לפתוח PRs ולנהל issues בשבילכם. מדריך ההקמה
קומיט (Commit)
"נקודת שמירה" ב-git. קומיטים קטנים ותכופים הם רשת הביטחון של עבודה עם סוכנים. פרק 3
ענף (Branch)
קו עבודה מקביל ב-git שאפשר למזג חזרה או לזרוק — המקום הבטוח לתת לסוכן לעבוד בו. פרק 3
Pull Request (PR)
בקשה למזג ענף, עם מקום לסקירה ודיון. נקודת הביקורת האנושית המרכזית על עבודת סוכנים. פרק 3
הזרקת פרומפט (Prompt Injection)
ניסיון לשתול הוראות לסוכן בתוך תוכן שהוא קורא — README זר, עמוד אינטרנט, תגובה. ההגנה: גבולות בקוד, לא אמון. מדריך האבטחה
הרשאות מינימום (Least Privilege)
לתת לכל סוכן וכלי בדיוק את ההרשאות שהמשימה דורשת — ולא אחת יותר. readonly כשאפשר. פרק 7
